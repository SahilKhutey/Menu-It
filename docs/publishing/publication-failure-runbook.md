# Publication Failure Runbook
**Troubleshooting Publishing Errors**

## Common Issues
- **409 Conflict (DRAFT_REVISION_STALE):** Another staff member saved changes while your screen was open. Refresh draft to reconcile.
- **422 Unprocessable Entity (NEGATIVE_ITEM_PRICE):** A dish has a price below 0.00. Correct the item price.
- **403 Forbidden (PERMISSION_DENIED):** Only Restaurant Owners and Managers have publication privileges.
