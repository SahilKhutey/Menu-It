# Publication Readiness Guide
**Pre-Flight Verification Standards**

## Validation Rules
- **Menu Metadata:** Non-empty title, supported currency code.
- **Categories:** Non-empty title, correct sort orders.
- **Dishes:** Non-negative pricing, valid allergen/dietary selections, unique identifiers.
- **Design Tokens:** Compatible theme version, registered layout template.
- **Safety Allowlist:** Internal notes and staff comments are automatically omitted.
