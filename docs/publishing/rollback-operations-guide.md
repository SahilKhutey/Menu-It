# Rollback Operations Guide
**Safe Historical Snapshot Reactivation**

## Procedure
1. Navigate to **Publishing -> Version History**.
2. Locate the historical version you wish to restore.
3. Click **Rollback to vX**.
4. Enter the required operational justification (e.g., "Reverting promotional prices").
5. Confirm. The system reactivates the previous snapshot instantly without deleting subsequent history.
