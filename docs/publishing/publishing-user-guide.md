# Publishing User Guide
**ModularMenu · Restaurant Operator Publishing Guide**

## Overview
Publishing your menu takes it from an editable draft into an active, publicly visible digital menu accessible by guests via your QR code or direct web link.

### Step-by-Step Publishing
1. **Edit Menu Draft:** Make your updates in the Menu Editor (categories, items, prices, dietary tags, photos).
2. **Pre-flight Readiness:** Navigate to **Publishing** in your menu dashboard. The readiness indicator reviews:
   - Valid menu title and prices
   - Required categories and dishes
   - Active theme and layout selection
3. **Review Warnings & Diagnostics:** If any non-blocking warnings appear (e.g., missing optional dish photo), decide whether to add photos or proceed.
4. **Publish New Version:** Click **Publish New Version**, optionally enter a brief note for your team's audit trail (e.g., "Updated weekend brunch menu"), and confirm.
5. **Instant Live Activation:** The menu is instantly updated across your public URL and QR code.
