# ARC-08 §21 — Accessibility & Responsive Design

- **WCAG 2.1 AA Compliance:** Minimum 4.5:1 contrast ratio between text tokens and background surface tokens.
- **Responsive Viewport Testing:** Fluid typography and flexible grids verified across 320px (iPhone SE), 360px (Android), 768px (iPad portrait), and 1280px+ (desktop).
- **Reduced Motion Support:** All theme transitions obey `@media (prefers-reduced-motion: reduce)`.
- **Keyboard Navigation:** Full tab stops, focus rings (`:focus-visible`), and ARIA landmarks across both settings and visual editors.
