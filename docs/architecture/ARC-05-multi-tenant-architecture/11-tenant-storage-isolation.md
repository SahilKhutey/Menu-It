# 11 — Tenant Storage & Media Isolation

## 1. Storage Key Hierarchy

Object storage paths are strictly generated by server-side logic:
`media/organizations/{organization_id}/restaurants/{restaurant_id}/{category}/{filename}`

Clients never supply storage keys directly.

## 2. Private Signed URLs

- Upload and download requests require authorization.
- Signed download URLs are generated using HMAC-SHA256 signatures with short expiration windows (e.g., 3600 seconds).
- Path traversal (`../`) and arbitrary bucket browsing are rejected.
