# 17 — Seed and Reference Data Strategy

## 1. Platform Reference Data

- Built-in theme presets (`modern-minimal`, `bold-culinary`, `dark-luxe`).
- Layout presets (`grid-compact`, `list-detailed`).
- Component definitions (`header-banner`, `food-item-card`).
- Subscription plans (`Starter`, `Professional`, `Enterprise`).

Seed execution is strictly idempotent and separated from tenant customer data.
